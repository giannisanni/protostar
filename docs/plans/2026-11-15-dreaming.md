# Dreaming: sleep trains on the model's own generations (pre-registered)

Goal: make "sleep" literal generative replay, so no ground-truth answer ever
enters consolidation. Code: `accretion/dream.py`, `lifetime.py --dream`.

- **Day:** each fact is seen once, as its raw doc. It is held in an episodic
  buffer: for now the context window, because one-shot fast memory across
  documents is 0% on v2_m1 (Aug); the slot tier replaces it if round 4 passes.
- **Night:** the model is cued with answer-free prompts (restructure variants
  cut before the object; tested: the object never reaches a cue) and
  completes them greedily. Those completions are the consolidation corpus.
- **Replay:** prior facts are re-dreamed from the current weights (empty
  buffer). The registry needs only cues.
- Wrong dreams are consolidated anyway (false memories) and counted.

Smoke (v2_m1, 60 facts, day in context): dream accuracy 67.4%, false 32.6%.
Dreams confabulate details ("founded by Nimbleton in 1855 / in 1844"). With
an empty buffer: 0%. Fast memory one-shot: 0% (as in August).

## Runs (v2_m1, engram substrate, 3 homogeneous corpora x 60, gate on, replay 30%)

| arm | consolidation corpus | replay corpus |
|---|---|---|
| control | ground-truth restructure | ground-truth restructure (= Aug 77.8% result) |
| dream | dreamed from the day | re-dreamed from weights |

## Decision (pre-registered)

1. Dreaming works as consolidation: dream-arm total facts retained (A+B+C
   after C, of 180) >= 50% of the control's.
2. Dreaming works as rehearsal: corpus A keeps >= 50% of its post-A recall
   after B and C (the Aug floor).
3. The dream arm's new-corpus recall is capped by dream accuracy (~67%), so
   it is also reported as recall / dream accuracy.
4. False memories: share of probes answering the WRONG object that a dream
   proposed, reported, no threshold.
Guards: val drift <= +0.05 (the gate enforces it).
