# Dreaming: sleep trains on the model's own generations (pre-registered)

Goal: make "sleep" literal generative replay, so no ground-truth answer ever
enters consolidation. Code: `accretion/dream.py`, `lifetime.py --dream`.

- **Day:** each fact is seen once, as its raw doc. It is held in an episodic
  buffer: for now the context window, because one-shot fast memory across
  documents is 0% on v2_m1 (Aug); the slot tier replaces it if round 4 passes.
- **Night:** the model is cued with answer-free prompts (restructure variants
  cut before the object; tested: the object never reaches a cue) and
  completes them greedily. Those completions are the consolidation corpus.
- **Replay:** prior facts are re-dreamed from the current weights (empty
  buffer). The registry needs only cues.
- Wrong dreams are consolidated anyway (false memories) and counted.

Smoke (v2_m1, 60 facts, day in context): dream accuracy 67.4%, false 32.6%.
Dreams confabulate details ("founded by Nimbleton in 1855 / in 1844"). With
an empty buffer: 0%. Fast memory one-shot: 0% (as in August).

## Runs (v2_m1, engram substrate, 3 homogeneous corpora x 60, gate on, replay 30%)

| arm | consolidation corpus | replay corpus |
|---|---|---|
| control | ground-truth restructure | ground-truth restructure (= Aug 77.8% result) |
| dream | dreamed from the day | re-dreamed from weights |

## Decision (pre-registered)

1. Dreaming works as consolidation: dream-arm total facts retained (A+B+C
   after C, of 180) >= 50% of the control's.
2. Dreaming works as rehearsal: corpus A keeps >= 50% of its post-A recall
   after B and C (the Aug floor).
3. The dream arm's new-corpus recall is capped by dream accuracy (~67%), so
   it is also reported as recall / dream accuracy.
4. False memories: share of probes answering the WRONG object that a dream
   proposed, reported, no threshold.
Guards: val drift <= +0.05 (the gate enforces it).

## RESULT 1: gate on (2026-11-15)

The +0.05 val gate is at the noise edge: the ground-truth CONTROL rolled back
cycle 1 at +0.0511 (August's identical run committed at +0.0453; the
substrate init is unseeded, so runs differ). Dream rolled back all three
(+0.056 / +0.062 / +0.051). Recall each sleep reached BEFORE rollback:

| cycle | control | dream | dream acc |
|---|---|---|---|
| 1 | 71.7% | 41.7% | 67.4% |
| 2 | 46.7% | 23.3% | 63.8% |
| 3 | 66.7% | 48.3% | 67.4% |

Dreams consolidate (cycle 1: 41.7 / 71.7 = 58% of control; 62% of dream
accuracy) but drift slightly more than ground truth. Retention is
unmeasurable with nothing committed, so the mandatory gate-off pair runs
next (same protocol as August). The gate verdict stands as reported: under
a +0.05 budget, dreaming as built does not pass.

## RESULT 2: gate off (the decision run)

| | control (ground truth) | dream |
|---|---|---|
| A after A / B / C | 70.0 / 65.0 / 56.7 | 33.3 / 30.0 / 25.0 |
| B after B / C | 50.0 / 41.7 | 18.3 / 18.3 |
| C after C | 65.0 | 36.7 |

| corpus A kept | 81.0% | 75.0% |
| val drift | +0.041 | **+0.058** |
| day dream accuracy | - | 67 / 67 / 56% |
| replay dream accuracy | - | 35% (c2), 25% (c3) |

Against the pre-registration:
1. Consolidation: 48 / 98 = **49%** of control (bar 50%). FAIL by one fact.
2. Rehearsal: corpus A keeps **75%** (bar 50%). PASS.
3. Recall / dream accuracy, cycle 1: 33.3 / 67.4 = 49%.
4. False memories: replay dreams are only as right as current recall (35% ->
   25%), so rehearsal re-consolidates whatever was mis-remembered. Wrong
   memories are rehearsed as faithfully as right ones.
Guard: drift +0.058 > +0.05. FAIL (control +0.041 passes).

Reading: dreaming works as REHEARSAL (old facts kept as well as with the
true answers) and half-works as CONSOLIDATION, capped by dream quality.
Levers: dream several times per cue and keep the majority answer
(self-consistency), which should both raise accuracy and cut confabulated
details, the likely source of the extra drift.

## RUN 3: consensus dreams (pre-registered 2026-11-15)

## FULL LOOP on xl_near (pre-registered 2026-11-15)

Step 1 (val check): the XL model's guard miss is real, not an eval artefact:
512-window val 3.498 with cache vs round 3's 3.342 (+0.16). Suspect: NoPE
attention gets position only from the causal mask, and an always-visible
cache breaks that. Fix candidate: learned bias on cached keys (separate run).

Day stream (`--day stream`): 60 facts packed whole into 512-token windows
with filler (~10 facts/window, 6 windows), streamed with the XL cache on;
each fact is dreamed from the cache state right after its window (its text
is NOT in context). Smoke: dream accuracy from cache 23% (27% voted) vs 70%
(80%) with the fact in context and 0% with nothing.

Arms (xl_near, engram tables, gate off, replay 30%, GPUs 0/1/2 in parallel):
control (ground truth), context-day consensus dreams, **stream-day
consensus dreams = the full loop**. Each cycle also logs recall BEFORE sleep
with memory empty (no-sleep control).

Decision for the full loop:
1. Learning: corpus A recall after its sleep (cache empty) >= no-sleep
   control + 10pp.
2. Keeping: corpus A keeps >= 50% of that after two more days.
3. Drift <= +0.05. Report everything relative to dream accuracy (~27%).

## FULL LOOP RESULT (2026-11-15): passes all three bars, at the margin

| xl_near, gate off, replay 30% | control (truth) | dreams, day in context | **full loop: day in XL cache** |
|---|---|---|---|
| no-sleep recall (day 1/2/3) | 0.0 / 3.3 / 3.3 | 0.0 / 0.0 / 3.3 | 0.0 / 1.7 / 3.3 |
| new corpus after its sleep | 58.3 / 43.3 / 66.1 | 43.3 / 43.3 / 66.1 | **10.0 / 21.7 / 20.3** |
| corpus A after A / B / C | 58.3 / 53.3 / 58.3 | 43.3 / 30.0 / 18.3 | 10.0 / 6.7 / 5.0 |
| corpus A kept | 100% | 42% (FAIL) | 50% |
| facts retained of 180 | ~101 | ~68 | ~24 |
| val drift | +0.010 | +0.018 | +0.018 |
| day dream accuracy | - | 80 / 97 / 98% | **15 / 35 / 29%** |
| replay dream accuracy | - | 38 / 27% | 7 / 10% |

Full loop vs pre-registration: (1) learning +10.0pp on corpus A (bar +10)
PASS at the threshold; days 2-3 +20 / +17pp. (2) corpus A kept 50% (bar 50)
PASS at the threshold. (3) drift +0.018 PASS. n=60 per corpus, so A is 6
facts -> 3 facts: technically through, statistically thin.

What it shows: the loop runs end to end with no ground truth after the day
itself, and every stage behaves as measured in isolation. Consolidation
turns ~2/3 of correct dreams into recall in every arm (10/15, 22/35,
20/29; context arm 43/80). The bottleneck is the first stage: dreaming
from the cache is 15-35% vs 80-98% with the day in context, at ~10 facts
per 512-token window (far denser than training). Rehearsal from weights
is only as good as current recall (7-10%), so old days fade.
Levers, in order: denser-fact curriculum or fewer facts per window for the
cache read; cache-key bias (val fix); larger cache.

## ROUND 7: xl_cue, dream-cue tuning (pre-registered 2026-11-16)

From xl_near (round 5). accretion/cuetune.py: window 1 states 1-12 facts
(facts.py doc format), window 2 asks them as dream cues (restructure() cut
before the answer, first cue at position 0), loss on answer tokens only,
gradients through the cache; + FineWeb LM loss each step. 1600 steps x 4
lanes, AdamW 5e-5. Held out: all lifetime-corpus subjects (seeds 100-102);
objects re-drawn per sample. NOTE for the paper: the cue FORMAT matches the
dream cues by design (it is format training); recall probes use a different
prompt (probe_prompt) and the no-sleep control stays the baseline.
Bars:
1. densecheck packed, voted >= 50% (xl_near 27%).
2. full loop (stream): corpus A >= no-sleep + 20pp, kept >= 50%, drift <= +0.05.
3. val 512 carried <= 3.52 (xl_near 3.498).
4. currprobe age-1 >= +80pp.
